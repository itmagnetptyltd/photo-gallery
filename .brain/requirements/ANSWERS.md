# Answers

Paste the client's reply here, under the question it answers. Their words, not a
summary — the wording behind every acceptance criterion stays in this file.

Then run `/resolve-ambiguities`. That writes the acceptance criteria, clears the
answered questions from both this file and `AMBIGUITIES.md`, and moves whatever
is now unambiguous from `draft` to `agreed`.

You do not have to answer all 28 at once. Answering any question unblocks the
requirements that carry it; the rest stay `draft`.
